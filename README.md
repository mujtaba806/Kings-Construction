# Kings Construction

Static website: HTML, CSS and JavaScript.

## GitHub upload
1. Extract this ZIP.
2. Upload index.html, style.css, script.js and the assets folder into your repository root.
3. For GitHub Pages, select Settings > Pages > Deploy from a branch > main > / (root).

Open index.html locally to preview. The enquiry form opens the visitor's email app; it has no server backend.

Photography is representative design inspiration, not a record of completed projects.
